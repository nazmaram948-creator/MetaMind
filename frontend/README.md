# SkillShift MY frontend

React + Vite. Talks to the FastAPI backend on the same origin (`/api`).

```bash
npm ci
npm run dev        # http://localhost:5173, proxies /api to http://localhost:8000
```

Run the backend in engine mode (`ENGINE_MODE=true`, see the root README). If the
backend is on another port, set `VITE_API_TARGET`, for example
`VITE_API_TARGET=http://localhost:8001 npm run dev`.

`npm run build` writes `dist/`. FastAPI serves it from the same port, which is the
setup for Replit.

Demo CV PDFs in `public/samples/` are synthetic and generated by
`data/scripts/make_sample_cvs.py`.
